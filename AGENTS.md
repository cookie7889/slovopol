# Проект: Словополь

Словесная головоломка для Яндекс.Игр: из 7 букв составить все слова (3–7 букв).Meta-уровень: карта путешествия по России, 30 остановок (MVP).

## Текущее состояние репозитория

Каркас: шаблон Vite + React + TS плюс созданная скелетная структура. Коммитов ещё нет, игрового кода нет. Реализовано только заглушками:

- `src/sdk/{types,real,mock,index}.ts` — пустые заглушки (`export {}` с русским комментарием), наполнять отдельной задачей.
- `src/data/levels.json` — `{"version": 1, "stops": []}`.
- `src/strings.ts` — `export const strings = {}`.
- `src/screens/`, `src/components/`, `src/game/` — пустые (только `.gitkeep`); `src/styles/base.css` — пустой.
- `scripts/package.sh` — существует и рабочий (см. Команды); `scripts/validate-dictionary.mjs` из плана ещё не существует.

`src/App.tsx` — по-прежнему демо-счётчик шаблона, не игровой код.

## Стек

- TypeScript + React + Vite. БЕЗ игрового движка.
- Yandex Games SDK (public/sdk.js), обёртка в `src/sdk` (real + mock) — заглушки созданы, реализация отдельной задачей.
- Состояние: useState/useReducer + Context. Без Redux.
- Стили: обычный CSS (один файл на экран). Без Tailwind/CSS-модулей на MVP.

## Команды

- `npm run dev` — локальная разработка (SDK в режиме mock)
- `npm run lint` — ESLint
- `npm run typecheck` — `tsc --noEmit`
- `npm run build` — `tsc -b && vite build`
- `npm run format` — `prettier --write src`
- `npm run preview` — превью собранного dist/
- `bash scripts/package.sh` — typecheck → build → zip `dist/` в `slovopol-YYYYMMDD-HHMM.zip` (артефакты чистить после проверки)

Gotcha: в `package.sh` архивирование через `7z a`, НЕ `zip` — утилиты `zip` на машине нет, sudo недоступен; не менять обратно.

Тестов и тестового фреймворка в репозитории нет — не пытайся запускать `npm test`.

Порядок проверки перед сдачей: `lint` → `typecheck` → `build`.

## Соглашения

- Язык интерфейса: русский. Комментарии в коде: русский.
- Хардкодить строки UI в компонентах запрещено — выносить в `src/strings.ts` (файл создан, пустой).
- Буква Ё нормализуется в Е везде (данные и ввод).
- Все слова — СУЩЕСТВИТЕЛЬНЫЕ в им. падеже ед. числа, без имён собственных.
- Шрифты ≥18px, зоны нажатия ≥48px, контраст WCAG AA (аудитория 45+).
- Внешние сетевые запросы запрещены, кроме SDK Яндекса. Шрифты и ассеты бандлим.
- Каждая фича должна работать и в mock-режиме (без интернета/SDK).
- `index.html` сейчас `lang="en"` — при русификации выставить `lang="ru"`.
