## Что сделано

- Создан компонент `WordsGrid` — сетка слов остановки по длинам: уникальные длины `main`-слов
  по возрастанию, в каждой группе по строке-ряду на каждое слово, слова внутри группы
  отсортированы по русскому алфавиту.
- Ячейка найденного слова — буквы; ненайденного — мягкая точка-заполнитель (структура слова
  видна, буквы не раскрываются). Ячейка 34×34 px, шрифт 20 px (требование ≥18 px).
- Бонусные слова — отдельная секция «Бонусные слова:» с чипами **только найденных** бонусов,
  у каждого чипа метка «Бонус».
- Анимации (только CSS, без библиотек):
  - `pop` — найденное слово «печатается»: scale .5→1, 180 мс, задержка 40 мс на букву
    (через CSS-переменную `--i`); перезапуск при одинаковых событиях подряд за счёт
    `flash.seq` в `key` ячеек (перезапускается только что найденное слово — чужие ряды
    не перезапускаются);
  - `shake` — тряска поля при неверном слове (реализована в W2-3, `Game.css`);
  - чип бонуса появляется с `pop` и меткой «Бонус»;
  - `prefers-reduced-motion: reduce` — transform-анимации заменены на смену прозрачности
    (`fade` в сетке, `fadeSoft` вместо тряски в `Game.css`).
- Сетка встроена в экран остановки `Game.tsx` (часть экрана, не отдельный экран/модалка),
  стоит после колеса и кнопок — по ГДД §3. Размер сетки не зависит от числа найденных
  слов, поэтому колесо не сдвигается (проверено замером: `wheelTop` 288 px до и после находок).
- Группы длин стоят рядом с переносом (`flex-wrap`): на широком экране сетка 408 px высотой
  вместо 672 px, на 360 px группы переносятся в столбец, горизонтальной прокрутки нет.
- Доступность: у ряда `aria-label` (найденное слово строчными; ненайденный ряд — с номером
  ряда, чтобы ряды различались), ячейки `aria-hidden`, у чипа бонуса `aria-label`
  «слово, Бонус» с `aria-hidden` на внутренних span, заголовки h1 → h2 → h3.
- Строки UI вынесены в `src/strings.ts` (группа `grid`), комментарии по-русски, редьюсер
  и `src/sdk/` не менялись.

## Отклонения от ТЗ / открытые вопросы

Заявленные отклонения (все одобрены ревьюером и оркестратором):

1. **Добавлен четвёртый проп `flash`** (`{ kind: FlashKind; seq: number } | null`). В ТЗ
   проп-сигнатура указана без него, но ТЗ же требует триггер анимаций по `flash.seq` —
   без него компонент не узнает о событии. Тип взят `import type { FlashKind }` из
   `../game/reducer`, редьюсер не менялся. **Проправлено в тексте промта.**
2. **Сортировка в `useMemo` по `main`, а не по `guessedMain`.** Сетка показывает все
   `main`-слова (включая ненайденные — пустыми клетками), поэтому сортировать нужно по
   `main`; `guessedMain` используется только как признак «найдено» (через `useMemo`-множество).
   Пересортировки при рендере нет: `useMemo(() => groupByLength(main), [main])`.
   **Противоречие в тексте промта устранено.**
3. **Триггер анимации — через `key` ячеек с `flash.seq`, а не через `useEffect`.** ТЗ
   предлагало `useEffect` как пример. Смена ключа перемонтирует ячейку и перезапускает
   CSS-анимацию; таймеров нет, cleanup не требуется, StrictMode-безопасно. Важная деталь:
   перезапускается только что найденное слово — чужие ряды не перезапускаются.
4. **Группы длин стоят рядом (`flex-wrap`), а не в одну колонку.** Чтобы высота сетки не
   разрасталась (408 px против 672 px на широком экране) и колесо не уезжало вниз.
   На 360 px группы выстраиваются в столбец — горизонтальной прокрутки нет.

Открытые вопросы и техдолг:

- **Сетка ниже первого экрана на узких экранах (360×740).** Порядок задан ГДД §3
