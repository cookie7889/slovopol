## Что сделано

1. `src/game/checkWord.ts` (создан) — чистая функция проверки слова по ГДД §2–3:
   - типы `WordStatus = 'correct' | 'bonus' | 'duplicate' | 'invalid'` и `CheckResult { status, word, reason? }` — ровно по ТЗ;
   - `checkWord(raw, stop, guessed: ReadonlySet<string>): CheckResult`;
   - порядок проверок зафиксирован и реализован буквально по ТЗ:
     1) `normalizeWord(raw)` → длина < 3 → `invalid/short`;
     2) кратность букв: каждая буква слова ∈ `stop.letters` И повторов букв в слове нет → иначе `invalid/letters`;
     3) слово уже в `guessed` → `duplicate`;
     4) слово есть в `stop.main` → `correct`;
     5) слово есть в `stop.bonus` → `bonus`;
     6) иначе `invalid/unknown`;
   - во всех ветках в `word` возвращается нормализованное слово (upper, Ё→Е);
   - чистая функция: без React, без DOM, без мутаций аргументов (`stop` и `guessed` только читаются, промежуточные `Set` создаются локально).
2. Всё остальное не трогал: `levels.ts`/`types.ts` без изменений, новых зависимостей нет, `enum`/`namespace`/`any`/`as any`/`eslint-disable` — нет, импорт типов — `import type`.

## Отклонения от ТЗ / открытые вопросы

- **Проверка «длина > 7» не делается** — как прямо указано в промте W2-1 («её гарантированно закрывает шаг 2»): в наборе 7 уникальных букв, поэтому слово длиннее 7 букв обязательно содержит повтор и попадает в `invalid/letters`. В декомпозиции (§2, W2-1) упоминался вариант «вернуть `short` и для >7» — расхождение трактую в пользу более свежего и явного промта; на игру это не влияет (слово >7 всё равно отвергается, различается только ярлык `reason`).
- `stop.main`/`stop.bonus` сравниваются напрямую (`includes`) — это корректно, потому что загрузчик `levels.ts` уже нормализует слова (upper, Ё→Е) при разборе JSON. Если бы сравнение шло по сырым данным, «ЛЁТО» не нашло бы «ЛЕТО».
- `guessed` трактуется как множество **нормализованных** слов (upper, Ё→Е) — как и возвращает `checkWord`; контракт зафиксирован в комментарии к сигнатуре.
- Внешние словари/hunspell не подключались (неделя 4). «Бонусные» = только слова из `stop.bonus`, никакого «угадывания редкости».
