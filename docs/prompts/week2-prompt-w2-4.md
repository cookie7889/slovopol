## Контекст

- В `GameState` уже есть `flash: { kind: 'ok' | 'bonus' | 'bad' | 'soft'; seq: number } | null` — `seq` монотонный счётчик, триггерит анимации при одинаковых событиях подряд.
- `guessedMain: string[]`, `guessedBonus: string[]` — источники данных сетки.
- Тестовые данные: остановка 1 — группы 3/4/5/6 букв, бонусных нет; остановка 3 — бонус `ОМЕЛА`.

## Что сделать

### 1. Создать `src/components/WordsGrid.tsx` + `src/components/WordsGrid.css`

Сетка по длинам (GDD §3.3):
- уникальные длины `main`-слов по возрастанию;
- в каждой группе — по строке-ряду на каждое слово; слова в группе отсортированы по алфавиту (стабильно, **без пересортировки при рендере** — сортировать в `useMemo` по `guessedMain`);
- ячейка: буква, если слово найдено; иначе пустая клетка с мягкой точкой-заполнителем (не «жёсткая» пустота — для 45+ видно структуру).

Пропсы: `{ main: string[]; guessedMain: readonly string[]; guessedBonus: readonly string[] }` — ненайденные слова показываются как «сломанные» ряды с точками, но буквы не раскрываются.

### 2. Бонусные слова

Найденные бонусные — отдельная секция-строка «Бонусные слова:» + чипы только НАЙДЕННЫХ бонусов (ненайденные не показывать). У каждого чипа — метка «Бонус» (из `strings`).

### 3. Анимации (CSS, без JS-библиотек)

- ячейки найденного слова: `@keyframes pop` (scale .5 → 1, ~180мс, задержка 40мс на букву — слово «печатается»);
- `flash.kind === 'bad'` → короткая тряска блока текущего слова: `@keyframes shake`, ±6px, ~300мс (в `Game.css`);
- `flash.kind === 'bonus'` → чип бонуса появляется с pop и меткой «Бонус»;
- `@media (prefers-reduced-motion: reduce)` — отключить transform-анимации, оставить только смену прозрачности.

Триггер анимаций — по `flash.seq` из reducer: подписаться на изменение `seq` (например, `useEffect` с зависимостью от `seq`, cleanup не обязателен если нет таймеров; если используешь таймеры — cleanup обязателен).

### 4. Встроить в `src/screens/Game.tsx`

Разместить сетку на экране остановки (часть экрана, не отдельный экран/модалка). Не сдвигать колесо — layout стабильный. Перенести данные из `GameState`.
