## Сквозные ограничения

- Node ≥18, ESM (`.mjs`), **без зависимостей** (чистый Node, никаких import из node_modules, кроме стандартных `node:fs` и т.п.).
- Файл не должен зависеть от React/TS — чистый Node.
- Валидатор проверяет только форму и целостность данных. Эталон hunspell-ru и генерация наборов — НЕ здесь (неделя 4, П12).
- Комментарии по-русски.
- `package.json`: новый скрипт — НЕ зависимость; ничего кроме `scripts` не менять.

## Что сделать

### 1. Создать `scripts/validate-dictionary.mjs`

Читает `src/data/levels.json` и проверяет:

- `version` — число; `stops` — массив; `id` уникальны;
- `letters`: ровно 7 символов `А-Я` (Ё нормализуется при проверке), все уникальны;
- каждое слово (main и bonus): 3–7 букв, только `А-Я`, без Ё (нормализовать и проверить, что Ё не встречалась в исходнике — **в данных Ё запрещена**), собирается из `letters` (нет чужих букв и повторов);
- дубликаты: внутри `main`, внутри `bonus`, и пересечение `main ∩ bonus` — пусто;
- `main` — не пустой; `fact` ≤ 180 символов.

### 2. Чёрный список

Если существует `scripts/blacklist.txt` (по слову в строке, `#` — комментарий), любое слово словаря из списка — ошибка. Создать файл-заготовку с инструкцией в шапке: полный стоп-лист подключается в неделю 4 вместе с эталонным словарём.

### 3. Вывод

- по строке на проблему: `Остановка {id}: {слово}: {причина}` (для проблем самой остановки — `Остановка {id}: {причина}`);
- в конце `OK: N остановок, M слов` либо `✗ найдено K проблем`;
- `process.exit(1)` при ошибках.

### 4. `package.json`

В `scripts` добавить: `"lint:dict": "node scripts/validate-dictionary.mjs"`.

## Критерии приёмки

- [ ] `npm run lint:dict` на текущем levels.json → `OK: 3 остановки, … слов`.
- [ ] Временная порча данных — валидатор ловит КАЖДЫЙ случай с понятным сообщением; после теста данные вернуть:
  - слово с чужой буквой (не из `letters`);
  - повтор буквы в слове (`ВОЛОВА`-подобное);
  - дубликат в `main`;
  - слово 2 буквы;
  - слово с Ё;
  - слово 8 букв;
  - повтор `id` остановки;
  - пустой `main`;
  - `fact` длиннее 180 символов;
  - слово из `main`, попавшее в `blacklist.txt` (временно добавить слово в blacklist, проверить, убрать).
- [ ] `npm run lint && npm run typecheck && npm run build` зелёные (скрипт их не ломает).
- [ ] Коммит `W2-6: валидатор словаря — структура, кратность, blacklist`.
