## Что сделать

Создать `src/game/score.ts`:

```ts
// Константы формулы — правятся без изменения механики (GDD §4)
export const POINTS_PER_LETTER = 5
export const BONUS_MULTIPLIER = 2

// очки за одно слово: длина × 5, бонусное × 2
export function scoreWord(word: string, isBonus: boolean): number

// звёзды — мера полноты (GDD §4):
// 1 ★ — все основные найдены; 2 ★★ — + хотя бы одно бонусное;
// 3 ★★★ — все слова, включая все бонусные.
// ВРЕМЕННОЕ правило для тестовых наборов без бонусных (totalBonus === 0):
// все основные найдены → 3 ★. Финальные остановки всегда содержат 2–3 бонусных.
export function starsFor(
  guessedMain: number,
  totalMain: number,
  guessedBonus: number,
  totalBonus: number,
): 1 | 2 | 3
```

Реализация:
- `scoreWord`: длина нормализованного слова × `POINTS_PER_LETTER`, при `isBonus` — × `BONUS_MULTIPLIER`.
- `starsFor`: если основные не все найдены (`guessedMain < totalMain`) → `1`; иначе если `totalBonus === 0` → `3` (временное правило тестовых наборов); иначе если найдены все бонусы (`guessedBonus >= totalBonus`) → `3`; иначе если найден хотя бы один бонус (`guessedBonus >= 1`) → `2`; иначе → `1`.
- Обе функции чистые; граничные случаи (0/0, `totalBonus === 0`) покрыть русскими комментариями в коде.
