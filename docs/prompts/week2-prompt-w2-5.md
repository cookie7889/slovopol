## Что сделать

### 1. Переход на экран завершения

Когда `guessedMain.length === stop.main.length`, Game.tsx через ~800мс (дать доиграть анимацию; таймер — с cleanup в cleanup-функции эффекта) уходит на экран завершения — навигация через App-колбэк `onComplete()` → App переключает состояние на `{ name: 'complete'; stopId: number }`.

### 2. Создать `src/components/Stars.tsx`

Инлайн-SVG звезда (path, **без icons.svg** — тот спрайт демо-Vite и уйдёт), пропс `filled: boolean`; 3 звезды в ряд, незаполненные — контуром, `aria-label` со строкой «{n} из 3 звёзд» (форматировать через `strings`).

### 3. Создать `src/screens/StopComplete.tsx` + `src/screens/StopComplete.css` (по GDD §3–4)

- заголовок «Остановка пройдена!»;
- звёзды по `starsFor(guessedMain.length, stop.main.length, guessedBonus.length, stop.bonus.length)`;
- город и факт (`fact` ≤180 символов, шрифт ≥18px, спокойно, без спешки);
- «Очки за остановку: {score}» и «Всего очков: {total}» (total — сумма по сессии, хранится в App как `useState`; сохранение — неделя 3);
- кнопка «Удвоить ×2» (главный акцент): по нажатию — `getSdk()` → `showRewarded()`:
  - `true` → dispatch `DOUBLE` (score × 2, `doubled: true`), total пересчитывается, кнопка становится неактивной с текстом «Очки удвоены»;
  - `false` или ошибка → тихий фолбэк: ничего не удваивать, кнопка остаётся доступной, сообщение «Реклама сейчас недоступна» (без вины игрока);
  - повторное удвоение запрещено (`doubled` в состоянии);
- кнопка «Дальше» (вторичный стиль): следующая остановка (`stopId + 1`, если есть в `getStopIds()`), иначе — «В меню» с текстом «Демо-маршрут пройден»;
- текстовая кнопка «К остановкам» (меню).

### 4. `src/game/reducer.ts` — действие `DOUBLE`

`DOUBLE`: `score *= 2`, `doubled: true`; повторный `DOUBLE` при `doubled === true` — игнор.

### 5. `src/App.tsx`

- состояние: добавить `{ name: 'complete'; stopId: number }`;
- `total` (сессионные очки) — `useState<number>`; при переходе на complete и при `DOUBLE` пересчитывать: при завершении остановки total += score; при удвоении total += score ещё раз (удвоенная разница). Реализацию итогового пересчёта держать аккуратно: двойного начисления не быть;
- передавать в StopComplete колбэки `onNext` (следующая остановка или меню) и `onMenu`.

### 6. `src/strings.ts`

Все строки экрана завершения, включая статусы рекламы и метки звёзд.

### 7. Комментарий-точка расширения

У кнопки «Дальше» комментарий: «здесь interstitial по GDD §10 (не раньше 2-й остановки, не в первые 3 минуты) — подключается в неделю 3 с картой».
