# «Словополь» — Game Design Document v1.0

**Версия:** 1.0 · **Дата:** 20.10.2026 · **Статус:** черновик для плейтеста Gate 1
**Платформа:** Яндекс.Игры (браузер, iframe; десктоп + мобильный)
**Аудитория:** женщины 45+/55+, РФ; короткие спокойные сессии
**Основа:** план разработки v1.0 (разделы 5.1, 6.1, 8.П1, 9, 11)

---

## 1. Видение

**Одной строкой:** спокойная словесная головоломка — составляйте русские слова из 7 букв и путешествуйте по России от Калининграда до Владивостока.

**Что игрок чувствует:** утренняя привычка на 5–15 минут: «разгадал слова — продвинулся по маршруту — узнал что-то о городе». Ностальгия, движение вперёд без спешки.

**Чего в игре нет никогда:** таймеров, проигрыша, штрафов за ошибку, навязчивой рекламы и обязательной регистрации. Отказ от рекламы не блокирует игру.

**Чем отличается от конкурентов ниши:** маршрут по России с узнаваемыми городами и тёплые факты о них — эмоциональный крючок для 45+, которого нет у «просто наборов букв».

## 2. Правила слов (зафиксировано; менять только через ревизию GDD)

- На каждой остановке набор из **7 уникальных букв**, тематически связанный с городом (пример из плана: Москва — «ВОКЗАЛТ»).
- Из букв составляются слова **3–7 букв**: только существительные в именительном падеже единственного числа.
- Запрещены: имена собственные, уменьшительные («котик»), аббревиатуры.
- **Ё = Е** везде: в данных, в вводе, в сравнении.
- На остановке **≥20 валидных слов**, из них **2–3 бонусных** — редкие слова 6–7 букв.
- Каждый словарь проходит машинную валидацию (`scripts/validate-dictionary.mjs`: эталонный словарь, кратность букв, чёрный список корней) и ручную выборочную проверку.

## 3. Core-цикл одной остановки

```
Карта → модалка города → Экран остановки → [ввод → проверка → награда] × N
→ «Остановка пройдена» → Карта
```

**Экран остановки (src/screens/Game.tsx):**
1. Колесо из 7 кнопок-букв (DOM-элементы по окружности) + поле текущего слова.
2. Кнопки «Стереть» и «Принять»; ввод с физической клавиатуры (keydown) равноправен.
3. Сетка отгаданных слов, сгруппированная по длине; счёт остановки; прогресс n/N слов.

**Ввод → проверка (src/game/checkWord.ts, чистая функция):**

| Результат проверки | Реакция игры |
|---|---|
| Новое слово | +очки, слово в сетку, CSS-анимация, звук «верно» |
| Новое бонусное | ×2 очки, метка «Бонус», отдельный звук |
| Уже угадано | мягкое сообщение, без штрафа |
| Неверно | короткая тряска поля, без штрафа |

**Награда и завершение:** когда найдены все основные слова — экран «Остановка пройдена»: факт о городе, итоговые очки, звёзды, кнопки «Удвоить очки» (rewarded) и «Дальше» (→ карта; здесь может показаться interstitial по правилам раздела 10).

**Психология для 55+:** ошибка — не событие, а вариант; поле никогда не блокируется; любое состояние можно продолжить без знания «игровых жаргонов».

## 4. Очки и звёзды

**Очки:** длина слова × 5 (3 буквы = 15 … 7 букв = 35); бонусные слова × 2. Рекорд остановки (`bestScore`) сохраняется.

**Звёзды — мера полноты, не скорости:**

| Рейтинг | Условие |
|---|---|
| ★ | все основные слова найдены (остановка пройдена) |
| ★★ | + найдено хотя бы одно бонусное слово |
| ★★★ | найдены все слова, включая все бонусные |

- Подсказки **не влияют** на звёзды — аудиторию 55+ не наказываем за помощь.
- Звёзды — визуальный прогресс на карте. Порогов «2 звезды, чтобы открыть следующую остановку» нет: открытие линейное.
- Формула очков — константы в `src/game/`; правятся без изменения механики.

## 5. Подсказки (2 вида)

| | Вид 1: бесплатная | Вид 2: за rewarded |
|---|---|---|
| Доступность | раз в 15 минут | без лимита, по явному нажатию |
| Кнопка | таймер до следующей бесплатной | «Подсказка за рекламу» → диалог «Смотреть рекламу? Подсказка за 30 секунд», отмена всегда работает |
| Эффект | открывает одну букву в неотгаданном слове | то же |

- Слово для подсказки выбирается автоматически: самое короткое неотгаданное; повторное нажатие открывает следующую букву того же слова.
- Подсказки копятся в прогрессе (`hints`); покупные пакеты (hints_5 / hints_20) пополняют тот же счётчик.
- Интервал 15 минут — стартовое значение, корректируется по плейтесту Gate 1.

## 6. Карта путешествия (мета-игра)

- Вертикально скроллящаяся лента 30 остановок: Калининград → … → Владивосток. SVG-пунктирная линия маршрута, узлы-кружки с номером и названием города. Никакого canvas — только DOM/SVG/CSS.
- Состояния узла: **пройдена** (зелёная, звёзды), **доступна** (акцентный цвет, пульс-анимация), **закрыта** (серая).
- Тап по доступной остановке → модалка: номер, город, факт (1–2 предложения, тон «приятель-проводник», ≤180 символов), ваш лучший счёт, кнопка «Играть».
- Автоскролл к текущей остановке при открытии экрана.
- Мета-цель, проговариваемая игроку: «пройти маршрут от Калининграда до Владивостока» — прогресс X/30 в шапке карты.

## 7. «Слово дня»

- Ежедневный набор: детерминированный выбор из levels.json по seed = YYYYMMDD — одинаковый для всех игроков.
- Одна попытка в день; очки по обычной схеме (бонусные ×2).
- После завершения — `sdk.setScore(boardId, points)`; boardId — константа в коде, сам лидерборд создаётся в консоли Яндекса.
- Экран результата: ваши очки, топ-10, ваша позиция. Лидерборд недоступен — тихий fallback без страшных ошибок.
- Streak: дни подряд — бейдж в модалке профиля (награды за streak — после MVP).
- Уже сыграно сегодня — показываем результат и «приходите завтра».

## 8. Онбординг: первые 90 секунд

Цель: первое отгаданное слово ≤ 60 секунд, без чтения инструкций. Без регистрации, без рекламы.

| Шаг | Что происходит |
|---|---|
| 1. Приветствие | Один экран: название, строка «Составляйте слова — и в путь по России!», одна крупная кнопка «Играть» |
| 2. Первая остановка | Лёгкий набор (много коротких слов). Над полем одна строка: «Нажимайте буквы, чтобы составить слово» |
| 3. Первое слово | Анимация + мягкое «Отлично!»; после 3 отгаданных слов строка-подсказка исчезает навсегда |

- Авторизация и облачные сохранения предлагаются мягко и не в первые 90 секунд; отказ не мешает игре.
- Первые 3 минуты сессии реклама запрещена (правило промта П9).

## 9. Экраны и навигация (MVP)

| Экран | Файл | Роль |
|---|---|---|
| Главная | src/screens/Home.tsx | «Играть» (продолжить), «Слово дня», профиль, настройки |
| Остановка | src/screens/Game.tsx | core-цикл (раздел 3) |
| Карта | src/screens/Map.tsx | маршрут, узлы, прогресс X/30 |
| Настройки | src/screens/Settings.tsx | звук, «Убрать рекламу», сброс прогресса (двойное подтверждение) |
| Модалки | src/components/ | город, «Остановка пройдена», магазин (3 IAP), профиль/streak, результат «Слова дня» |

Навигация линейная; состояние — useState/useReducer + Context; все строки — в `src/strings.ts` (заготовка i18n).

## 10. Монетизация (правила игры с рекламой)

| Формат | Где используется | Ограничения |
|---|---|---|
| Interstitial | только переход «остановка пройдена → карта» | максимум каждая вторая остановка; никогда в геймплее; не в первые 3 минуты |
| Rewarded | подсказка; удвоение очков остановки | только по явному действию игрока, честный диалог, отказ не наказывается |
| IAP | noads (199–299 ₽, непотребляемый), hints_5 (99 ₽), hints_20 (249–299 ₽, потребляемые) | noads → все рекламные вызовы no-op; статусы синхронизируются при каждом старте |
| Sticky-баннер | — | выключен на MVP |

## 11. Прогресс и сохранения (кратко; полное ТЗ — промт П8)

- Схема: `{ version, mapProgress: { [stopId]: { stars, bestScore } }, dailyStreak, lastDailyDate, hints, settings, updatedAt }`; поле version — для будущих миграций.
- Запись: localStorage мгновенно → sdk.setPlayerData в фоне (debounce 3 с). Чтение: сначала локально для мгновенной отрисовки, затем облако; конфликт версий — по updatedAt.
- Гость играет сразу и сохраняется локально; облако — после мягкой авторизации.

## 12. Доступность, стиль, звук

- Шрифт: Rubik или Nunito (кириллица, OFL, woff2 в бандле). Базовый размер ≥18px, кнопки ≥48px, контраст WCAG AA.
- Без таймеров, лимитов попыток и «страшных» красных состояний; ошибки — мягкие.
- Тон текстов: тёплый «приятель-проводник», без CAPS и канцелярита.
- Звук: 6 эффектов (тап, верно, неверно, остановка пройдена, покупка, «Слово дня» готово) + переключатель в настройках.
- Арт v1 («art last»): SVG-кружки, пунктирный маршрут, CSS-градиент фона. Иллюстрации — после Gate 1, если механика «втянула».

## 13. Скоуп: что в MVP, что отложено

| В MVP (карта 1, недели 1–8) | Отложено (после метрик Gate 3) |
|---|---|
| 1 карта × 30 остановок + факты | карты 2–5, сезонные тематические |
| Ядро: колесо, ввод, валидация, очки, звёзды | мультиплеер, кланы, чаты |
| Подсказки: бесплатная + rewarded | валюта, магазин, battle pass |
| Interstitial + rewarded + 3 IAP | EN-локализация (только заглушка strings.ts) |
| «Слово дня» + лидерборд + streak-бейдж | награды за streak |
| Онбординг 3 шага, настройки, 6 звуков | собственная аналитика (хватает консоль + GameAnalytics) |

## 14. Метрики успеха (сводка Gate 3)

D1 ≥ 35% · D7 ≥ 15–18% · средняя сессия ≥ 8 мин · ARPDAU ≥ $0.015 · CR в rewarded ≥ 30% · оценка ≥ 4.5.
Источники: консоль Яндекса + GameAnalytics (события: старт/финиш остановки, показ rewarded, покупки).
Железное правило: контент не масштабируем, пока D7 ниже порога.

## 15. Открытые вопросы (закрываются плейтестом Gate 1)

1. Интервал бесплатной подсказки (15 минут — стартовое значение).
2. Понятность критериев звёзд тестерам 45+.
3. Восприятие объёма «20+ слов на остановку» — при перегрузе смягчаем онбординг и порядок слов, но не правила.
4. Финальный список 30 городов карты — фиксируется при генерации контента (промты П12/П13).
