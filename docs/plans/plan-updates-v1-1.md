## 1. ЗАМЕНИТЬ раздел 4.2 целиком

### 4.2 Подключение SDK (актуально на 21.10.2026)

1. Документация: **yandex.ru/dev/games/doc/ru/** → раздел «SDK» → «Подключение и использование»
   (прямая ссылка: yandex.ru/dev/games/doc/ru/sdk/sdk-about). Раздел LoadingAPI:
   yandex.ru/dev/games/doc/ru/sdk/sdk-game-events.
2. **Файл sdk.js скачивать НЕ нужно** — платформа раздаёт его сама по пути /sdk.js.
   В index.html остаётся тег (путь абсолютный, это требование платформы):

```html
<script src="/sdk.js"></script>
```

3. Локально /sdk.js недоступен (404 — норма): обёртка src/sdk включает mock.
   404 в консоли локальной разработки игнорируем.
4. Для тестирования с РЕАЛЬНЫМ SDK без перезаливки zip — официальный пакет:

```bash
# prod-окружение (нужен ID черновика):
npx @yandex-games/sdk-dev-proxy -p dist --app-id=<ID черновика>
# dev-окружение (регистрация не нужна, SDK замокан Яндексом):
npx @yandex-games/sdk-dev-proxy -p dist --dev-mode=true
```

5. API сверен с текущей докой: ysdk.leaderboards.setScore() (getLeaderboards()
   УСТАРЕЛ), ysdk.getPayments() → payments.purchase()/getPurchases(),
   ysdk.environment.i18n.lang, ysdk.deviceInfo.isMobile(),
   ysdk.features.LoadingAPI?.ready(), ysdk.features.GameplayAPI?.start()/.stop().
