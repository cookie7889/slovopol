## 1. Сквозные ограничения недели 2 (действуют на ВСЕ задачи, из AGENTS.md + GDD)

1. TypeScript strict (`tsconfig.app.json` как есть: `strict`, `noUnusedLocals`, `noUnusedParameters`, `verbatimModuleSyntax`, `erasableSyntaxOnly`). Следствия, на которых спотыкаются бесплатные модели:
   - `enum` и `namespace` запрещены (`erasableSyntaxOnly`) — только union-типы и `as const`;
   - импорт типов — только `import type { … }` (`verbatimModuleSyntax`);
   - никаких `any`, `as any`, `// eslint-disable`.
2. **Новые зависимости запрещены** (AGENTS.md). Тест-фреймворк не добавляем (AGENTS.md: тестов нет, `npm test` не запускать). Критерии проверяются вручную.
3. Логика — чистые функции в `src/game/`, без React и без DOM. Компоненты — в `src/screens/` и `src/components/`. Состояние — `useReducer` + props, Context на неделе 2 не нужен.
4. Строки UI — только `src/strings.ts` (комментарий-группировка по экранам). Хардкод текста в JSX запрещён.
5. Стили — обычный CSS, **один файл на экран** (`Game.css`, `StopComplete.css`, `WordsGrid.css`); общие токены — `src/styles/base.css` (CSS-переменные). Без Tailwind/CSS-модулей.
6. Аудитория 45+: шрифт базовый ≥18px, кнопки и плитки букв ≥48×48px, контраст WCAG AA, никаких таймеров и красных «страшных» состояний, ошибка = мягкое сообщение.
7. Буква Ё → Е везде (данные, ввод, сравнение). Слова — существительные, им. падеж, ед. число, без имён собственных, уменьшительных и аббревиатур.
8. SDK — только через `getSdk()` из `src/sdk`; никаких обращений к `window.YaGames` вне `src/sdk/real.ts`.
9. Прогресс игры в неделе 2 живёт в памяти (React state). localStorage для прогресса НЕ подключаем (неделя 3, W3-2); в localStorage может появиться только ключ mock-SDK `slovopol:save`.
10. Внешние сетевые запросы запрещены. `console.log` в игровом коде не оставлять (логи разрешены только внутри `src/sdk/`).
11. React 19 + StrictMode: в dev-режиме эффекты монтируются дважды — все `useEffect` обязаны возвращать cleanup; на одноразовое монтирование не рассчитывать.
12. Трогать файлы вне задачи запрещено. Комментарии в коде — по-русски. Перед сдачей: `npm run format` (prettier: одинарные кавычки, без точек с запятой — сниппеты в этом ТЗ уже в этом стиле).

### W2-1 — checkWord.ts: чистая функция проверки слова

**Файлы:** создать `src/game/checkWord.ts`.

**Что сделать:**
1. Сигнатуры (реализация по GDD §2–3):
```ts
import type { StopData } from './types'
import { normalizeWord } from './levels'

export type WordStatus = 'correct' | 'bonus' | 'duplicate' | 'invalid'

export interface CheckResult {
  status: WordStatus
  word: string // нормализованное слово (upper, Ё→Е)
  reason?: 'short' | 'letters' | 'unknown' // только для status='invalid'
}

// raw — что набрал игрок (может быть в любом регистре, с Ё)
// guessed — уже найденные слова этой остановки (main + bonus)
export function checkWord(raw: string, stop: StopData, guessed: ReadonlySet<string>): CheckResult
```
2. Порядок проверок (важен, зафиксирован):
   1) `normalizeWord` → длина < 3 → `invalid/short` (длина > 7 невозможна: ограничение колеса, но проверить и вернуть `short` тоже);
   2) кратность букв: слово собирается из `stop.letters` без повторов (буквы набора уникальны по GDD §2, поэтому достаточно: каждая буква слова ∈ набора И повторов букв в слове нет) → иначе `invalid/letters`;
   3) слово уже в `guessed` → `duplicate`;
   4) слово есть в `stop.main` → `correct`;
   5) слово есть в `stop.bonus` → `bonus`;
   6) иначе `invalid/unknown`.
3. Функция чистая: без React, без DOM, без мутаций аргументов.

**Критерии приёмки:**
- [ ] Ручная проверка в dev-режиме (временно можно из консоли через импорт модуля): для остановки 1 `checkWord('вокзал', …)` → `correct`; `'ЁлКА'`-подобное слово с Ё нормализуется; `'ЗАЛ'` второй раз → `duplicate`; `'ЗОНТ'` (буквы не из набора) → `invalid/letters`; `'КЗАОЛВТ'`-подобный мусор → `invalid/unknown`; `'ТО'` → `invalid/short`.
- [ ] На плитках-буквах с повторами проверка ловит и случай «двух одинаковых букв в слове» (напр. `'ВОЛОВА'` → `invalid/letters`).
- [ ] typecheck/lint/build зелёные. Коммит `W2-1: checkWord (correct/bonus/duplicate/invalid)`.

**Ограничения:** НЕ подключать hunspell и внешние словари (неделя 4). «Бонусные» в неделе 2 = только слова из `stop.bonus`, никакого «угадывания редкости».
